## Repository hygiene

- Add a license only after the repository owner chooses one.
- Keep branch protection and required checks aligned with the actual CI workflow.
- Do not add badges claiming test coverage, release status, or production readiness without evidence.
- Pin GitHub Actions to full commit SHAs before adopting a stricter supply-chain security policy.
