# Code of Conduct

## Our commitment

We want participation in this project to be welcoming, respectful, and constructive for people with different backgrounds and levels of experience.

## Expected behavior

- Be considerate and respectful.
- Explain disagreements with evidence and context.
- Give feedback about code and ideas, not personal characteristics.
- Welcome beginner questions and make technical explanations accessible.
- Accept constructive feedback gracefully.

## Unacceptable behavior

- Harassment, insults, or discriminatory language.
- Publishing someone else's private information.
- Deliberate intimidation or sustained disruptive behavior.
- Repeatedly derailing technical discussions.

Project maintainers are responsible for clarifying and enforcing these standards in project spaces.
