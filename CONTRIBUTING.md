# Contributing

Thanks for taking an interest in this project. Contributions can include code, documentation, bug reports, workflow improvements, and clearer setup instructions.

## Before opening an issue

- Search existing issues to avoid duplicates.
- Include enough detail for someone else to reproduce the problem.
- Remove credentials, tokens, and personal customer information from logs and screenshots.

## Suggested workflow

1. Fork the repository.
2. Create a focused branch from the default branch.
3. Make a small, clearly scoped change.
4. Test the behavior you changed.
5. Update documentation when setup, configuration, or behavior changes.
6. Open a pull request with a concise summary and testing notes.

## Pull request checklist

- [ ] The purpose of the change is clear.
- [ ] The change is limited to a coherent scope.
- [ ] Tests were added or updated where appropriate.
- [ ] Documentation was updated where needed.
- [ ] No secrets or private customer data are included.
- [ ] The pull request explains how the change was tested.

## Contribution style

Be respectful, specific, and constructive. Explain technical disagreements with evidence and focus feedback on the work rather than the person.
